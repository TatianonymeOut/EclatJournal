# Changelog

All notable changes to Éclat Journal are documented here.

## [0.1.0] — 2026-08-18

First public local-first MVP for iOS and macOS.

### Included

- Multiple daily journal check-ins with a mood emoji, intensity, and free-text context.
- An original daily reflection selected entirely on device.
- A journal timeline, calendar, local mood trends, and health notes for personal record-keeping.
- Local import of photos, audio files, and short videos.
- French native SwiftUI interface shared by iOS and macOS.
- Public privacy, security, contribution, and medical-disclaimer documentation.

### Privacy and scope

- No account, advertising SDK, analytics SDK, project-operated backend, or hidden cloud processing.
- Health-related notes are personal records only; the app does not provide diagnosis, treatment, or emergency support.

### Verification

- The macOS test suite passed locally with Xcode on 18 August 2026.
- The repository's GitHub Actions workflow builds and tests the macOS target.
